# gitops-lab

GitOps source of truth for the OCI Always Free k3s lab: Argo CD Applications under `argocd/`, Kustomize overlays under `apps/`. Deploys `tinycloud-platform`.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `sasiruLK/gitops-lab`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
